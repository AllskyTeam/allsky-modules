Centre Radius
Important: the circle settings are only stored after you click Save below and then the green Save button in the Module Manager.
Drag the circle to move it, drag the square handle (or use the mouse wheel) to resize. Buttons move 1 pixel per click, Shift-click for 10, hold to repeat. Keyboard: arrow keys move the centre 1 pixel (with Shift, 10); + / - change the radius 1 pixel, PageUp / PageDown change it 10. Keys work on any keyboard layout, whenever you are not typing in a field.
